# 煎饼果子店 · Mini Game

一个轻量的网页小游戏，灵感来自“沙威玛”玩法。把配料拖到铁板上，按订单制作煎饼果子，别糊锅！

## 启动

无需构建，直接打开 `index.html` 即可。若需要本地服务器（更接近真实环境，支持拖拽坐标正确换算），可以使用：

```bash
# Python 3
cd jianbing-game
python3 -m http.server 8080
# 或者 Node
npx serve -s . -l 8080
```

然后访问 `http://localhost:8080`。

## 操作说明
- 将“面糊/鸡蛋/酱/配料”从右侧拖到画布内的铁板区域。
- 按 F 对折，拖拽任意配料到右侧虚线框“打包区”完成出餐。
- 空格或“暂停”按钮可以暂停/继续。

## 评分与订单
- 订单会有倒计时，超时会扣评分。
- 出餐时根据火候、配方匹配度、是否对折来计算分数并换算为金币。

## 自定义
- 在 `game.js` 中的 `INGREDIENTS` 和 `RECIPES` 可增删配料和配方。
- 画布与布局在 `index.html`/`style.css` 中调整。
